Privacy Policy for Nnamaka’s Personal n8n Automation Effective date: October 18, 2026 Operator: Nnamaka Nwakaihe Contact: nnwakaihe@gmail.com Overview Nnamaka’s Personal n8n Automation is a privately operated automation application that connects a locally hosted n8n instance to the operator’s Google account. It is intended for the operator’s personal use and is not offered as a public service. This policy explains how the application accesses, uses, stores, and shares Google user data. Google Data Accessed Depending on the permissions granted and the workflows enabled, the application may access: Google Drive file names, identifiers, metadata, and file contents. Google Docs document contents and associated metadata. Google account information made available through the authorized connection. The application uses this access only to perform workflows configured by the operator. Depending on the permissions granted, those workflows may read, create, update, organize, or delete files and documents. How Data Is Used Google user data is used to execute personal automation tasks, including retrieving documents, processing information, organizing files, and creating or updating documents. The application does not sell Google user data or use it for advertising. Storage and Security The application runs in a locally hosted n8n environment. OAuth credentials and tokens are stored by that installation so that authorized workflows can access Google services. Depending on the n8n configuration, file contents, document contents, metadata, and workflow inputs or outputs may also be retained in execution history, logs, local storage, or backups. The operator is responsible for protecting the host computer, restricting access to the n8n installation, and safeguarding credentials and stored data. No method of electronic storage or transmission can be guaranteed to be completely secure. Data Sharing and Third-Party Services The application exchanges data with Google as necessary to perform authorized Google Drive and Google Docs operations. The application does not intentionally transmit Google user data to other external services. Data may nevertheless be retained in storage or backups configured by the operator. The public website hosting this policy is informational. The application is not designed to publish Google documents, OAuth tokens, or workflow execution data to that website. Data Retention and Deletion Data stored in Google Drive and Google Docs remains in the operator’s Google account unless an authorized workflow or the operator modifies or deletes it. Local copies and workflow execution records are retained according to the operator’s n8n settings and storage practices: The operator can delete locally retained data and execution records. Copies in backups or external services, if any, must be deleted separately according to the relevant storage configuration or service’s deletion process. Authorization and Revoking Access The application accesses Google data through an OAuth connection authorized by the Google account owner. The owner may stop the workflows, remove the Google credential from n8n, or revoke the application’s access through their Google Account’s third-party connections settings. Revoking access prevents further authorized access through that connection. It does not automatically delete previously stored workflow data, logs, backups, or copies held by other services. Changes to This Policy This policy may be updated when the application’s workflows, data handling, or connected services change.
